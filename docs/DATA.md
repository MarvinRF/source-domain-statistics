# Data

This repository does **not** redistribute any dataset. All experiments use
[Amazon Reviews 2023](https://amazon-reviews-2023.github.io) (McAuley Lab,
UCSD), which is subject to its own terms of use.

## 1. Download

From the release page, download the review file and the metadata file of
each category below:

| Role | Category | Files |
|---|---|---|
| Source domain | Books | `Books.jsonl.gz`, `meta_Books.jsonl.gz` |
| Target (music) | CDs_and_Vinyl | `CDs_and_Vinyl.jsonl.gz`, `meta_CDs_and_Vinyl.jsonl.gz` |
| Target (movies) | Movies_and_TV | `Movies_and_TV.jsonl.gz`, `meta_Movies_and_TV.jsonl.gz` |
| Target (games) | Video_Games | `Video_Games.jsonl.gz`, `meta_Video_Games.jsonl.gz` |
| Off-domain covariance control | Grocery_and_Gourmet_Food | `meta_Grocery_and_Gourmet_Food.jsonl.gz` |

Put all files, unrenamed, in one directory and point the code to it:

```bash
export ACW_DATASETS_DIR=/path/to/amazon2023
```

## 2. Derived data

Everything under `data/` is generated by the pipeline and is git-ignored:

```
data/
├── raw/          # 5-core filtered items, user histories, ground truth, splits (per domain)
└── processed/    # embeddings, user profiles, whitening matrices, trained modules
```

See [REPRODUCIBILITY.md](REPRODUCIBILITY.md) for the commands that build each
artifact and the expected sizes and counts.

## 3. What a user is and what counts as relevant

- **Users** are reviewers with at least five interactions in Books *and* in
  the target category (5-core applied per domain pair).
- **Source signal**: the user's chronological Books history; profiles use the
  last 10 books.
- **Relevance (primary)**: the target-domain items the user actually reviewed
  (`ground_truth_real.json`), restricted to the indexed catalog.
- **Relevance (secondary)**: every catalog item sharing a depth-2 category
  with one of those items. Reported only as a coarse genre-matching metric,
  never as the headline result.
